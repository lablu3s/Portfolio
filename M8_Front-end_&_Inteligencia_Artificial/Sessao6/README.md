# Skodji Digital_M8_Sessao6

### Temas:
-Html semântico
-Responsividade de sites
-Frameworks do Materialize

### Tarefas:
Exploração do website do Materialize, que apresenta o Material Design, que é uma linguagem de design criado pela Google como forma de combinar os principios clássicos de um bom design com a inovação e tecnologia. Os conteúdos apresentados no Materialize são frameworks e templates que auxiliam na criação de um website.
1. Entrar no site https://materializecss.com/ e baixar os conteúdos do Materialize;
2. Seguir os passos do Setup do Materialize, para a criação do diretório do nosso website e das pastas do Html, CSS e Javascript;
3. Explorar o site do Materialize para extrair os frameworks associados a diferentes elementos da criação de um website funcional;
4. Explorar os templates existentes para a criação de um website com o minímo de setup, através da coleção do Materialize;
5. Dentro do VS Code, importar os ficheiros correspondentes aos elementos a adicionar a estrutura do website, como por exemplo:
   1. Para CSS, a cor do background ou dos textos e outras propriedades visuais;
   2. Para Html, a adição de botões, menus de navegação, icones, cards ou badges;
   3. Para Javascript, a criação de features, como o website reage com a interação do usuário (ex: ao interagir com o menu de navegação, o mesmo é redirecionado para a secção correspondente);
   4. A criação de formulários, com diferentes funcinalidades;
   5. Tornar o website responsivo, para ecrãs menores, a criação de um menu de navegação lateral.
