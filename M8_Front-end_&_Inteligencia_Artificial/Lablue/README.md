# LABLUE'S | Pixel Space

Um portfólio web pessoal apresentado como uma pequena aventura de videojogo. O projeto combina uma estética retro de *pixel art* com a trajetória de Lorette Araújo, engenheira de energias renováveis e freelancer digital, para apresentar o seu perfil, projetos, competências e formas de contacto.

## Experiência e funcionalidades

- **Página de entrada:** introduz o universo LABLUE'S SPACE e convida a explorar o portfólio.
- **Perfil:** apresenta a experiência e áreas de atuação através de um perfil inspirado em personagens de videojogos.
- **Projetos:** organiza os trabalhos em categorias de áreas digitais e IA, análise e crescimento, e engenharia, com filtros interativos.
- **Competências:** mostra as competências num formato inspirado num inventário de jogo.
- **Contacto:** apresenta opções para entrar em contacto num quadro de missões (*quest board*).
- **Interface interativa:** inclui navegação adaptada a dispositivos móveis e controlo de som.
- **Design responsivo:** adapta o layout a diferentes tamanhos de ecrã.

## Tecnologias

O projeto é feito com **HTML, CSS e JavaScript**, sem dependências de build. A identidade visual usa tipografia pixel art e recursos gráficos guardados na pasta `images/`.

## Como abrir

Abra `index.html` num navegador para ver a página de entrada. Para aceder diretamente ao portfólio completo, abra `portfolio.html`. Não é necessária instalação.

## Estrutura

```text
Lablue/
├── index.html           # Página de entrada
├── landing_page.html    # Página de convite para o portfólio
├── portfolio.html       # Perfil, projetos, competências e contacto
├── style.css            # Estilos da página de entrada
├── style_portfolio.css  # Estilos do portfólio
├── script.js            # Filtros e interações da interface
├── images/              # Avatares e elementos gráficos
└── README.md            # Documentação do projeto
```
