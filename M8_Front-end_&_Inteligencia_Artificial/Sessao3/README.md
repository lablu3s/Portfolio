# Skodji Digital_M8_Sessao3

### Tarefa 1:
1. Fomos instruídos a baixar e instalar os seguintes softwares: **Visual Studio Code**, **Git** e o **GitHub Desktop**.
2. Depois de ter todos os softwares instalados e configurados, fizemos o acesso a nossa conta no GitHub.

### Tarefa 2:
No **Visual Studio Code**, o objetivo foi explorar as suas ferramentas e implementar os conhecimentos adquiridos durante as sessões (Html e CSS).
1. Criar um novo repositório para as sessões do Módulo 8;
2. Neste repositório criar um ficheiro Html `index.html`;
3. Dentro do index, praticamos a estrutura e formatação em Html, como adicionar Títulos `<title>`, Cabeçalhos `<h1>`, Paragráfos `<p>`, Imagens `<img src>`, com as suas respetivas tags;
4. Criar um ficheiro `style.css`, onde testamos como personalizar diferentes aspetos do nosso Html.
