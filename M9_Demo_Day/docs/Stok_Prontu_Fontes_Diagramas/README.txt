Fontes editáveis dos diagramas do Desenho do Sistema Stok Prontu

- arquitetura.mmd: componentes e integrações do sistema
- casos_de_uso.mmd: atores e casos de uso
- modelo_dados.mmd: entidades e relações (com ambiguidade assinalada)
- interacoes_venda.mmd: sequência de venda e emissão do recibo
- interacoes_offline.mmd: sequência de operação offline e sincronização

Formato: Mermaid. Os diagramas foram renderizados para PNG e incorporados no DOCX/PDF entregues separadamente.
Os elementos assinalados como hipótese ou pendência devem ser confirmados com os responsáveis do produto.
